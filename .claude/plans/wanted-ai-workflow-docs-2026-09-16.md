# 원티드 AI 개발 절차 문서 동기화

Graft의 코드 관계 탐색과 Archify의 구조·실행 흐름 시각화를 사수 개발 절차에 추가한다. AI 개발 문서와 에이전트 규칙·하네스 지침을 연결하고, 동일한 500자 완료형 원고를 레포 제출 문서·작업 폴더·원티드 입력란에 반영한다.

G1~G5 PASS. 문서 설계와 최종 리뷰는 메인 직접 수행. 기존 사용자 변경은 유지한다. 완료형은 실제 문서에 추가한 개발 절차를 가리키며 설치·실행 결과를 꾸미지 않는다. 최종 수정하기는 사용자 클릭.

완료: 개발 절차·에이전트 규칙·하네스·README·아키텍처·제출 원고를 동기화했다. 500자·원고 동일성·AGENTS/CLAUDE 일치·diff 형식을 확인했다. 원티드 입력 확인, 최종 수정하기 미클릭. 문서 변경이므로 서비스 테스트는 실행하지 않았다.
