# Phase 24 — 5개 부서 채용 미션 데모

원천: PRD §3-3·§8, ADR-059. 상태: 로컬 구현·검증 통과 / 운영 미반영.

1. 기획·인사·프론트개발·백엔드개발·디자인 미션/자료/샘플 산출물과 합성 시드 보강.
2. 브라우저 내 단계 기록·안전한 파일 선택·근거 포함 제출·결과/진행 확인. 서버 쓰기·LLM·영속 저장 0.
3. 부서별 PC/모바일 완주, 검증·부서 격리·초기화·무전송·기존 데모 회귀.

실제 지원자 제출·채점·배포는 범위 밖이다. Graft·Archify 결과가 없으면 수동 의존 관계 기록과 누락 범위를 검증 문서에 명시한다.

결과: 단위 1,101개·브라우저 17개·lint·build 통과. 로컬 시드 7부서·155항목·42답변. [실행 기록](../../docs/verification/department-hiring-demo/README.md).
