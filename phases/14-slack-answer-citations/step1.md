# Step 1 — 운영 반영·실제 Slack 확인·제출 캡처

## 입력
- ADR-049·050, step0, `docs/verification/slack-answer-citations-2026-09-15.md`.
- 사용자가 선택한 제출 장면: 실제 Slack에서 `@사수`에게 질문하고 근거 인용을 확인하는 화면.

## 승인된 운영 검증에서 실행할 작업
1. 검증한 커밋 스냅샷을 배포한다. promote 전 현재 운영 배포 ID를 조회해 롤백 대상으로 기록한다.
2. 운영 게스트 읽기 E2E와 Slack 웹훅 무서명 401을 확인한다. DB 마이그레이션·시드·기능 플래그 변경은 필요 없다.
3. 동의·연결된 QA 부서 채널에서 합성 질문을 `@사수`로 1회 보낸다. 실제 LLM 처리와 스레드 답변을 기다린다.
4. 답변과 모든 인용문·작성자·시각·원문 링크를 Slack 화면에서 확인한다. 링크는 실제 원문으로 이동해야 한다.
5. 검증 기록에는 식별자·상태·인용 검증 결과만 적는다. 실제 운영 발언·질문 본문을 로그에 남기지 않는다.
6. 제출용 캡처에는 합성 테스트 내용만 사용한다. 실제 Slack 화면을 캡처하며, HTML 재현 화면을 실제 캡처라고 쓰지 않는다.
7. 현재 제출 5장과 README에서 중복되는 웹 ASK 장면을 실제 Slack ASK 장면으로 교체한다. 링크·크기·읽기 쉬움을 검수한다.

## 상태
코드 검증과 배포 대상 준비 후 운영 반영 승인을 확인한다. 실제 Slack 캡처는 아직 없다. 단계가 끝나기 전에는 제출 문서에 운영 검증 완료라고 쓰지 않는다.
