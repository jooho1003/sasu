## 작업

`app/(site)` 정적 서버 컴포넌트로 메인과 개인정보 처리 안내를 만든다. 메인은 설계된 10개 섹션과 실제 게스트 실행 캡처를 사용한다. 외부 CTA와 채용 예고편 섹션은 `lib/site.ts`가 안전한 링크를 돌려줄 때만 렌더한다. `/demo`와 깊은 게스트 화면, `/no-membership`에 메인·데모·파일럿 CTA를 연결한다.

## Acceptance Criteria

- 1440/390px에서 가로 넘침 0, h1 문구 일치, `/demo` 링크 존재, 콘솔 오류·쓰기 요청 0.
- 환경 변수 미설정 또는 잘못된 형식이면 관련 버튼이 없다.
- 예고편은 발행 경로 또는 명시적 프리뷰 플래그가 있을 때만 보인다.
- 개인정보 안내에 처리 목적·항목·보관·위탁·권리·안전성 조치와 법률 검토 전 초안 표시가 있다.
- `npm run lint`, `npm run build`, `npm run test`, 사이트·게스트·예고편 E2E 통과.

## 금지사항

- 자체 문의 폼, 사용자 이메일 하드코딩, 경쟁사 실명 비교, 출처 없는 수치, 학습 미사용 단정을 추가하지 않는다.
