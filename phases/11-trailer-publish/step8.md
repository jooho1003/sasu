# Step 8 — 예고편 회사·제품 이름 생성 지시 보완

## 입력
- ADR-045 가상화 생성·공개 검토, 기존 `lib/trailer-generation.ts`와 테스트.
- 클로드 인수인계: 가상 회사명을 새로 짓도록 한 지시 때문에 실제 회사명과 겹치는 출력이 생겼다. 기존 데모 스냅샷은 이미 수정·시드되었다.

## 구현
- 새 회사·제품 고유명사를 생성하지 않고 협력사·공급사·고객사·업무 도구·주력 제품·서비스 등 일반 명칭을 사용하도록 지시한다.
- 사람 이름·수치는 가상화, 원문 마스킹·인용 검증·공개 승인 절차는 유지한다.
- 이 지시는 이름 충돌을 줄이는 보완이며 자동으로 모든 실명을 검출한다는 보장이 아니다.

## 검증
`npm run test -- tests/trailer-generation.test.ts`의 추가 테스트 실패를 확인한 뒤 구현했다. 전체 lint/build/test에 포함한다.

새 LLM 생성·운영 시드·기존 스냅샷 수정은 수행하지 않는다. 변경은 이후 새 생성에 적용된다.
