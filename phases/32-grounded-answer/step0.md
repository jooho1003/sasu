# ASK 질문 → 결정 → 원문 확인 보완

- 기준: PRD §3·§8, ADR-066. 2026-09-22 사용자 개발 지시.
- 범위: 권한을 유지하는 결정 검색, 문서·회의 원문 열람, 검증된 문단 기반 답변, 실패/개선 및 재사용 방법 원고.
- 완료 조건: 관련 단위 테스트, 격리 SQL 하니스, lint/build/test, 1440/390px 브라우저 확인. 운영 반영은 별도 승인.
- 후속 요청: 실제 DB 연결 사용자 흐름 검증. 로컬 Supabase의 실제 Auth·RLS·pgvector와 Groq/Voyage, Next.js·브라우저를 연결해 질문→결정→원문→권한 회수·삭제를 확인한다.
- 실패 사례: 최신 3건 밖 결정 누락, 미임베딩 결정 누락, 부분 인용에 근거 없는 결론, 부정어 생략, 삭제/권한 회수 뒤 원문 열람.
- Graft·Archify: 현재 MCP·PATH·vendor/skills 탐색에서 실행 도구가 확인되지 않았다. 대체로 실제 import/호출 검색과 소스 검토, Mermaid 구조도를 기록한다. 도구 실행 결과는 누락이며 도구를 실행했다고 주장하지 않는다.
- 실행·결과: `docs/verification/grounded-answer-2026-09-22/README.md`와 이 step의 완료 요약에 연결한다.
