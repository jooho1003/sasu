# 공개 데모 수정 및 실행 결과

PRD §3·§8, ARCHITECTURE §4.5, ADR-061 반영. 공개 메뉴의 심사 계정 요구 제거, 좌측 메뉴 토글/스크롤바, 기능 설명 지도, 실제 근거 카드 이동, 질문 근사 매칭/샘플 음성 전사, 영업 합성 기록 64개, 문서별 결정과 보류 후속 기록, 예고편 직접 체험을 구현했다.

검증: lint 통과, 분리한 webpack 프로덕션 빌드 통과, Vitest 94개 파일/1,105개 테스트 통과, 신규 및 기존 게스트 Playwright 13개 통과. 4개 공개 부서 전체 메뉴, 1440/390px 동선, 비인증 접근 및 DB/AI 호출 수 불변을 확인했다.

[실행 기록과 캡처](../../docs/verification/demo-workspace/README.md), [수동 의존/흐름 기록](../../docs/verification/demo-workspace/flow.md).

누락: Graft/Archify 도구 미제공으로 도구 기반 그래프·다이어그램 검증은 수행하지 못했다. 해당 도구 결과를 실행했다고 주장하지 않는다. 운영 배포·시드 변경·커밋/푸시는 수행하지 않았다.
