# Step 3: 심사위원 데모와 회귀 인계

상태: 미실행. step2 통과 후 수행. 원천은 PRD REC-05, 상세 설계 §8·V11~V12, ADR-055·056.

## 작업

- 별도 파일 준비 없이 바로 재생하는 합성 회의 WAV·전사·수정본·근거 요약을 배포물에 포함한다. 텍스트 예시 5개도 유지한다.
- reviewer는 최대 60초 실제 캡처/재생/내려받기를 메모리에서 수행한다. IndexedDB/DB/Storage/LLM에 녹음 데이터를 전송하지 않는다.
- 녹음한 내용과 합성 예시 전사 결과를 명확히 구분한다. 권한 거절/마이크 없음도 예시 흐름으로 완주한다.
- production-like 환경에서 네트워크 본문·업무 DB/Storage/jobs/llm_calls 전후를 확인한다. 실제 음성의 analytics/로그 전송도 검사한다.
- 기존 ASK·VTT·문서·녹음 파일·카드·원장·권한/동의·11개 데모 기능을 회귀 검증한다.

## 완료 기록

`docs/verification/browser-meeting-recording/README.md`에 step0~3 실행 자료, 기기별 지원 표, 용량 측정, 미지원 범위, 운영 반영 체크를 연결한다. 개발/검증 완료와 운영 배포는 별도 상태로 기록한다. 통과한 모드만 플래그로 공개하고 문제 시 새 녹음 진입만 끌 수 있게 한다. 기존 파일 검토·이미 저장된 원본 열람은 유지한다.
