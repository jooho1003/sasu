# Step 1 — 설정·문서·조직 관리 후속 개선

## 입력
- PRD §5 S5·S7·S11~S14, ADR-044·048.
- 사용자 요청: 설정·문서·관리 화면까지 UI/UX 완성도 높이기.

## 구현
- 설정을 멤버·동의 / 연결 관리 / 자료 가져오기로 나누고 상태와 다음 행동을 표시한다.
- 문서는 업로드, 목록 선택, 인용 포함 상세를 구분한다. 로딩·빈 목록·오류를 구별하고 재시도를 제공한다.
- 문서 목록의 연속 재조회, 채널 선택 시 설정 재조회로 입력이 초기화되는 문제를 수정한다.
- 실사용·데모 관리자 화면의 공통 탐색, 현재 위치, 표·상태 표시를 정리한다.
- 기존 API·RLS·동의·인용·기능 플래그·데모 읽기 전용 정책을 유지한다.

## 완료 조건
- lint → build → test 실행.
- 390px·1440px에서 설정 탐색, 문서 선택/검색/로딩/오류, 관리자 탐색을 검증한다.
- 회귀 테스트로 재조회 횟수와 종료 조건, 폼 입력 보존을 확인한다.
- 실사용 읽기와 게스트 동선 검증, 스크린샷을 docs/verification에 기록한다.
