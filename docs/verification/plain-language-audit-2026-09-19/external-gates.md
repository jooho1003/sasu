# 외부 조건 확인 — 2026-09-20

## 실제 모델 문체 검증

`node scripts/review-qa.mjs llm-style`은 로컬 Supabase와 합성 근거를 사용해 기존 `llm.structured()` 경로로 호출했다. Groq가 HTTP 400 / `spend_limit_reached`를 반환했다. 한도 오류임을 확인한 뒤 추가 호출을 중단한다.

[llm-samples.json](llm-samples.json)에 첫 실패와 나머지 대기를 기록했다. 성공한 문장 0건이며 문체 위반율은 계산할 수 없다. 6개 질문·3개 카드·2개 요약의 실제 모델 검증은 한도 복구 뒤 다시 실행해야 한다. 합성 응답으로 통과 기록을 대체하지 않았다. 결제·사용 한도 설정은 바꾸지 않았다.

## 쇼케이스 데이터 감사

`npm run audit:showcase`를 저장소 환경의 기존 쇼케이스에 **읽기 전용**으로 실행했다. 대상 부서 1개에서 아래 표시가 발견되어 종료 코드는 1이었다. 본문·질문 원문은 출력하거나 이 문서에 복사하지 않았다. 아래 검색 결과는 중복될 수 있으므로 고유 기록 수로 합산하지 않는다.

| 검색 종류 | 일치 건수 |
|---|---:|
| 항목의 `[QA-` | 2 |
| 질문의 `[QA-` | 3 |
| 항목의 `[합성 QA` | 10 |
| 결정의 `[합성 QA` | 3 |
| 항목의 `E2E-` | 22 |

이번 검증이 이 기록들을 만든 것은 아니다. 로컬 하니스만 쓰기 대상으로 사용했다. 운영 기록을 삭제·이동하거나 append-only 결정을 변경하지 않았다. 운영 담당자의 정리·분리 판단과 재감사가 필요하다.

## 사람 확인과 운영 반영

- [reading-test.md](reading-test.md)의 비개발자 5분 읽기 테스트는 실행하지 않았다. 결과 칸은 비워 두었다.
- 동의 전문은 [consent-diff.md](consent-diff.md)에 제안만 남겼다. 법률 확인·재동의 판단 전에는 적용하지 않는다.
- 운영 배포, 제출 스크린샷 교체, README 제출 썸네일과 노션 가이드는 변경하지 않았다.
- Graft·Archify 자동 분석 결과는 없다. [수동 의존 관계 검토](dependency-review.md)에서 누락 범위를 명시했다.
