## 화면·동작 증거

- 19개 화면 × 1440/390px: [큰 화면 측정](screens-1440.json), [모바일 측정](screens-390.json), 같은 이름의 PNG·본문 TXT. 측정 결과 가로 넘침·브라우저 오류·게스트 쓰기 요청 0건.
- 모바일 첫 결정 카드는 화면 위에서 195.1875px에 표시된다. [첫 화면](dashboard-390-viewport.png). 첫 4개 뒤 더 보기, 설명 접기, 단일 main 구조를 확인했다.
- 원문 링크는 `?item=<UUID>`로 정확한 항목을 연다. 최근 목록 필터와 독립적으로 조회하고 현재 세션 RLS·부서 권한을 검사한다. 삭제되거나 권한이 없는 원문은 노출하지 않는다.
- 근거를 원문별로 묶고 검색·단일 선택·선택한 근거 표시를 제공한다. 같은 제목이어도 ID가 다르면 서로 다른 원문으로 유지한다.
- 카드의 5개 정보, 채용 체험의 점수 설명, 관리자 모바일 안내·탐색, 자료 검토의 실패·재시도와 원본 접근 상태를 확인했다.

## 완료로 표시하지 않은 항목

실제 모델 11개 표본은 Groq `spend_limit_reached`로 성공 0건이다. [llm-samples.json](llm-samples.json)의 문체 위반율은 null이며 합성 문장으로 대체하지 않았다. 비개발자 읽기 검증은 [reading-test.md](reading-test.md)에 준비만 했다.

2026-09-23 후속: [실제 표본 재실행](../model-resume-2026-09-23/README.md)에서 한도 차단 없이 11건씩 두 번 측정했다. 질문은 ADR-066의 원문 선택·거절을 확인하고 문체 분모에서 제외했다. 카드·요약 5건의 문체 준수는 공통 지시 보강 후 2/5(40%)로 여전히 목표 미달이다. 위의 0건은 당시 실패 기록으로 보존한다.

동의 전문·개인정보 법률 본문은 유지하고 [동의 문구 제안](consent-diff.md)을 분리했다. 쇼케이스 읽기 감사의 기존 QA 표식, 운영 배포·사람 판정·제출 후 반영 조건은 [external-gates.md](external-gates.md)에 기록했다. [수동 의존 관계 검토](dependency-review.md)는 Graft·Archify 도구 출력의 누락을 명시한다. 제출 자료와 운영 배포를 바꾸지 않았다.

전체 명령·실행 기록은 [남은 step 검증](../remaining-steps-2026-09-20.md)을 참고한다.
