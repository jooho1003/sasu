# 현재 코드 제품·데모 E2E — 2026-09-29

격리된 `.vercel/review-qa` Supabase만 대상으로 `node scripts/review-qa.mjs setup`을 실행하고, migration 0063·0064를 로컬에 적용했다. QA harness가 URL을 `localhost`/`127.0.0.1`로 검사한다. 로컬 조직의 녹음 스위치를 켜고 `node scripts/review-qa.mjs build`로 프로덕션 빌드를 만든 뒤 `node scripts/review-qa.mjs recording-product-test`를 실행했다. 종료 뒤 QA DB의 임시 조직 스위치 행을 삭제했다. 원격 `.env`의 DB에는 쓰지 않았다.

첫 실행에서 제품 2건은 QA 설정 오류로 실패했다. 녹음 키 환경변수와 E2E의 DB 컨테이너 이름이 기본 로컬 환경을 가리켰다. QA 전용 키를 생성하고 격리 DB 이름을 주입하도록 고친 뒤 동일 명령을 다시 실행해 **9건 모두 통과(약 1.5분)**했다.

- 데모 7건: 로컬 녹음 재생·다운로드, 마이크 거절 대안, 공개 심사 링크, 화면 데이터 로딩, 쓰기 차단, 모바일 폭, 결정·질문·자료 검토.
- 인증 제품 1건: Chrome에서 합성 한국어 음성 캡처 → 암호화 구간 저장 → 로컬 워커 검증·Groq 전사 → 구간 검수·확정 → 발행 요약·인용·분류 확인. `step2-product-local-synthetic.png`는 이 실행에서 갱신했다.
- 조직 스위치 1건: 녹음 진입 숨김·직접 URL 차단·기존 녹음 자료 배지 유지, 다시 켰을 때 진입 확인.

합성 입력의 브라우저·로컬 서비스 연결 증거다. 실제 Windows/macOS 장치와 Meet/Zoom 소리, 20분 정확도, 운영 CSP/제공사/배포 게이트는 [검증 연결](README.md)에 남겼다.
