## 최신: 공간 탐색형 오피스 재구현 (2026-09-15 02:31 KST)

사용자가 최초 격자 UI의 품질을 거부해 ADR-041 기준으로 체험 화면을 재구현했다. 아래 최초 슬라이스 기록은 이력이며 **현재 UI는 전체 화면 Canvas 월드**다.

- 문서·대화·수첩·결정은 네이티브 dialog로 표시한다. dialog가 열리면 이동을 멈추고 포커스를 가둔다. Escape/닫기로 월드에 복귀한다. 목록 모드와 초안/단서 상태를 공유한다.
- 모바일은 카메라가 캐릭터를 따라가고 화면 방향 버튼을 길게 눌러 이동할 수 있다. 기존 합성 사례·인용·기본 비활성·저장/전송 없음 경계는 유지한다.

## 구현과 실행 방법

`/trailers`에서 입장 → 합성 퀘스트 3개(협력사 단가, 출시 범위, 고객 요청) → 장소 탐색·NPC 질문 → 단서 선택·결정·이유 작성 → 기록실 비교 → 전체 회고를 완주한다. 정답·점수·합불 판정은 없다.

서버 컴포넌트가 환경 변수와 합성 계약을 확인하고 클라이언트에 직렬화한다. Next.js 스킬의 서버/클라이언트 경계를 적용했다. React/CSS 자체 맵이며 방향키/WASD·바닥 클릭·F 상호작용·장소 버튼을 제공한다. 목록 모드는 같은 상태와 콘텐츠를 사용한다.

PowerShell에서 로컬 프리뷰 실행:

```powershell
$env:SASU_TRAILER_PREVIEW_ENABLED = 'true'
npm run dev -- --port 3110
```

브라우저: `http://localhost:3110/trailers`. `SASU_TRAILER_PREVIEW_ENABLED`가 정확히 `true`가 아니면 404다. 이 플래그는 인증 수단이 아니며, 활성화된 인스턴스의 방문자는 모두 합성 체험에 접근할 수 있다. 검색 색인은 제외한다.

`.env.local`이나 운영 환경 변수는 수정하지 않았다. 확인용 로컬 실행은 해당 프로세스에만 플래그를 전달한다. 기존 `/demo`·홈에는 링크를 넣지 않았다. 외부 배포는 실행하지 않았다.

기존 Vite 설정 및 NO_COLOR/FORCE_COLOR 경고는 있었으며 테스트 실패는 없다. `npm run test`는 별도 구성인 실DB RLS 테스트를 포함하지 않는다. 이번 변경은 DB/SQL을 수정하지 않아 실DB RLS·라이브 Slack·LLM 평가를 실행하지 않았다.

E2E는 동일 프로덕션 빌드에 대해 활성 서버 3107, 비활성 서버 3108을 독립 실행하고 종료한다. 기존 E2E 설정과 분리한 `playwright.trailer.config.ts`를 사용한다.

1. 1440px 맵: 세 퀘스트 완주, 미작성 제출 차단, NPC 근거, 단서 중복 방지, 모드 전환 시 초안·선택 유지, 사례와 다른 결정 허용, 전체 회고·재시작 확인.
2. 1440px 목록: 동일 콘텐츠·검증·회고 흐름 완주.
3. 390px 모바일 목록: 동일 흐름 완주, 가로 넘침 없음.
4. 방향키/WASD 이동, 바닥 클릭 이동, F로 가까운 장소 열기, 장소 제목 포커스, 새로고침 시 초기화.
5. 비활성 서버: HTTP 404, 응답에 시나리오 제목 없음.

세 완주 테스트에서 API·fetch/XHR/eventsource·비조회 HTTP 요청 0건, 쿠키 0개, localStorage/sessionStorage 0개, 브라우저 런타임 오류 0건을 확인했다. 브라우저 관측만으로 서버의 모든 동작을 증명하는 것은 아니므로 코드 경계도 확인했다: 이 경로와 컴포넌트·순수 모듈은 Supabase/LLM/워커를 import하지 않으며 합성 fixture만 받는다. 운영 DB 쿼리 결과를 주장하지 않는다.

단위 테스트는 없는 사실 ID·위조/공백 인용·잘못된 기록실 선택·중복 ID·알 수 없는 내부 필드·미확인 단서·이유 길이 및 공백을 거부한다. 이 검증은 인용 무결성 검사이며 실데이터 발행의 기밀 검사나 승인 게이트가 아니다.

## 다음 개발 범위

1. lead 세션과 `can_see()`/RLS로 입력 후보를 제한한다. `leads_only`를 인용한 원장 제외, 정정된 결정의 최신 행 판별, 원시 발언 제외를 SQL 테스트로 먼저 고정한다.
2. `llm.structured` + jobs로 가상화 초안을 만들고, 공개 사실집/대화 계약을 검증한다. 원문과 생성 초안은 공개 클라이언트에 전달하지 않는다.
3. 원문 겹침 임계·고유명사 사전·마스킹 검사·lead 문장 승인·발행/철회를 구현한다. 승인된 공개 payload만 체험 화면에 공급한다.
4. 파일럿 lead의 실제 업무 유사성 검수와 기밀 차단 검증을 진행한 뒤 R1 전체 완료를 판정한다. R2 지원자 계정·동의·평가는 기존 컨셉의 별도 선행 조건을 따른다.
