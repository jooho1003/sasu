# 운영 적용과 남은 검증 실행

2026-09-23 사용자가 외부 계정·실기기·사람 검수·쇼케이스 판단, Graft/Archify 실행 기록과 자동 배포까지 진행하도록 요청했다. 앞선 커밋·머지 요청도 이어서 적용한다. 이 요청으로 운영 DB 및 자동 배포의 사용자 승인 조건은 충족했다. 실제 사람 수행·계정 인증 결과는 별도로 검증한다.

1. 운영 환경과 DB를 대조하고 schema-only 사본을 `.vercel/release-schema-before.sql`에 비공개 보관한다. 해시만 검증 기록에 남긴다.
2. 적용 예상 결과가 0052·0053·0054뿐임을 확인한 뒤 순서대로 적용한다. 원격·로컬 54개 migration 일치를 확인한다.
3. `main` 자동 배포 보류 설정을 제거한다. 이미 검증한 앱 코드와 DB 변경을 Git PR로 반영하고 Vercel 생산 배포·도메인 응답을 확인한다.
4. Graft 0.19.0 구조 분석은 LLM/외부 코드 전송 없이 격리 컨테이너에서 실행한다. Windows 설치 실패도 보존한다. Archify는 공식 저장소 커밋 `8809b273c278a813a47fa37698864779c0d4cf08`의 스킬로 명세·HTML·검증 영수증·브라우저 측정을 생성한다.
5. 외부 계정의 인증 상태와 설치 기록, 공개 데모 QA 표식을 읽기 전용으로 검사한다. 인증되지 않은 제공자를 합성 응답으로 통과시키지 않는다.
6. 실제 마이크·공유 음성 시험과 로그인한 사용자의 Whisper 전사는 참여자의 조작으로 확인한다. 녹음·전사 본문은 검증 로그에 남기지 않는다.
7. 사람 읽기 검수는 실제 수행 기록을 받아 반영한다. 개발 참여자의 사용자 검수와 독립 비개발자 읽기 검수는 구분한다.

실제 발송 대상이 정해지지 않은 Slack 메시지는 보내지 않는다. 쇼케이스 데이터는 삭제하지 않으며 append-only 결정은 수정하지 않는다. 기존 과거 증거 파일을 덮어쓰지 않는다.
