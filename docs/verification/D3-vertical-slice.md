## 실패 시 그날 반영할 강등

5분 안에 배포 URL에서 흐름을 완주하지 못하면 사람 판정 후 아래 세 가지를 즉시 PRD §8-0·§4에 반영한다.

1. 회의 봇을 시도하지 않고 `.vtt`/`.txt` 전사 업로드 전용으로 확정한다.
2. Notion API 대신 원칙 문서 텍스트 붙여넣기로 확정한다.
3. 임베딩 검색 대신 키워드 검색으로 확정한다.
