## 구현 판정

- 브라우저 음성 입력은 오디오를 저장하지 않고 Groq Whisper로 텍스트화한 뒤, 사용자가 수정·확인하여 기존 권한 인지 Q&A로 제출한다.
- 문서는 lead만 업로드할 수 있고, source visibility·RLS·`can_see()`를 거쳐 요약과 인용을 노출한다.
- 문서 요약은 인용이 원문에 문자열로 포함될 때만 저장·렌더한다. 인용이 없는 요약은 실패 처리한다.
- 생체 음성 식별·화자 지문은 구현 범위에서 제외했다. 화자 권한은 기존 동의된 멤버·전사 라벨 경로를 따른다.
