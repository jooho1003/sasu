## 사람 실측과 다른 점

- **조작 주체:** Playwright가 앱 화면의 입력칸·버튼을 눌렀다. 입력은 사람처럼 한 글자씩 쳤지만, 사람의 읽기·판단 시간은 없다. 따라서 이 결과는 "5분 안"의 하한선이고 사람 사용성 실측을 대신하지 않는다.
- **로그온 방식:** 새 계정으로 Windows에 직접 로그인하지 않았다. 현재 사용자의 화면 세션에서 새 계정 자격으로 실행했다(보조 로그온, 새 계정 프로필 로드). 앱 설치·설정·암호화 저장소는 새 계정 것이지만, 바탕화면과 작업 표시줄은 기존 사용자의 것이다.
- **설치:** 무인 설치(`/S`)라 설치 마법사 클릭이 없다. 설치 파일을 브라우저가 아니라 프로그램으로 받아서 인터넷 표시(MOTW)가 없고, SmartScreen 경고와 "추가 정보 → 실행" 단계도 나타나지 않았다.
- **패널 고정:** 녹화 중 다른 창으로 초점이 옮겨가도 패널이 숨지 않도록, 실행 직후 앱이 지원하는 `settings.set({ panelPinned: true })`를 호출했다(화면의 "고정 풀기" 표시).
- **메일 확인:** 코드는 Claude가 Aside 브라우저의 Gmail 화면에서 읽어 앱에 전달했다. 코드 값은 출력·저장하지 않았고, 전달용 임시 파일은 앱이 읽자마자 지웠다.

## 실행 환경 메모

- 설치된 ffmpeg 9.0과 휴대용 8.1.2는 NVENC API 13.1(드라이버 610 이상)을 요구했다. 이 PC 드라이버 591.86은 API 13.0이라 인코더를 열지 못했다. 드라이버는 업데이트하지 않고 GyanD 공식 릴리스의 ffmpeg 7.1.1 essentials(zip SHA-256 `04861d33…`)를 임시 폴더에서 썼다.
- 이 Claude 세션은 Windows 세션 0이라, 녹화·실행은 일회용 예약 작업 → 탐색기 경유로 화면 세션 1에서 돌렸다. PowerShell `Start-Process -Credential`은 "액세스가 거부되었습니다"로 실패했고, .NET `ProcessStartInfo`(사용자·암호·프로필 로드)는 성공했다.
- 끝난 뒤 정리했다. 예약 작업 삭제, 임시 계정과 프로필 삭제, 임시 암호 파일 삭제, 공용 작업 폴더와 내려받은 ffmpeg 삭제.
