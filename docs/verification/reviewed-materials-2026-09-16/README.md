2026-09-16 · phase 20/21 · ADR-054. 개발 및 격리 환경 검증이며 운영 배포 기록은 아니다.

## 구현 결과

- 음성/문서 자료 검토 목록과 상세 페이지. 음성 원본 비공개 보관, 새로고침 후 다시 듣기, 구간 이동, 전체 전사, 텍스트 추가·수정·삭제, 저장/재접속, 검색, 최초 변환문 비교, 버전 충돌, TXT/MD 내보내기.
- 문서 전문 확인·교정 후 확정. 재추출은 현재 교정과 분리된 후보로 표시하고 유지/교체를 선택한다. 확정 전 source/items가 없고, 확정 후 기존 요약/검색 작업을 시작한다.
- 사용 중지·재확정은 이전 근거를 무효화한다. 원본만 삭제와 자료 전체 삭제를 구분한다. 취소/삭제/동의 철회 후 늦은 결과가 되살아나지 않게 SQL에서 검증한다.
- Slack 플랜/보존 확인값·변경 예정일·채널별 수집 범위, 현재 권한·동의가 유효한 수집본의 MD/체크섬 JSON 내보내기. 삭제 원문·다른 부서·미동의 발언은 제외한다. 첨부 실물/전체 이력 보관 완료로 표시하지 않는다.
- 운영자용 AES-256-GCM 백업/격리 DB 복원 검증 도구. 실제 운영 저장소·정기 일정·서비스 복구 자동화는 설정하지 않았다.

SQL 검증은 부서/멤버/동의/데모 경계, 직접 행 변조·워커 RPC 호출 거부, 중복 생성/확정, 저장 충돌, 원문 출처 위조 거부, 계좌/이메일/전화 마스킹, 취소 후 늦은 완료, 참여자 동의 철회 시 녹음/전사/근거 폐기를 포함한다. 문서는 TXT·MD·CSV·JSON·한국어 PDF·DOCX를 실제 추출하고 마지막 문장을 확인했다. 손상 PDF는 실패 상태와 확정 차단을 확인했다.

최종 검토에서 비활성 소스의 문서 요약이 남는 경로를 발견했다. 소스 비활성화 시 요약을 비우고 늦은 요약 저장도 SQL 트리거에서 비우며, 현재 비활성 소스의 요약은 RLS 직접 조회에서도 숨기도록 수정했다. PGlite와 실제 로컬 PostgreSQL/세션을 사용하는 TTS E2E에서 늦은 요약 저장·직접 읽기 차단을 재검증했다.

실제 PDF 테스트 중 서버 worker 설정 누락을 발견해 `pdf-parse`를 서버 외부 패키지로 설정하고 worker를 명시했다. [공식 문제 해결 안내](https://github.com/mehmet-kozan/pdf-parse/blob/main/docs/troubleshooting.md)를 적용한 뒤 개발 서버와 production build에서 다시 통과했다. 최초 실패 결과를 최종 성공으로 숨기지 않고 수정·재검증했다.

게스트 첫 실행은 스트리밍된 부서 링크가 나타나기 전에 테스트가 목록을 읽었고, 로컬 Slack 서명 비밀값 미설정으로 500이 반환됐다. 링크 표시를 기다리도록 테스트를 수정하고 운영 값 대신 로컬 전용 서명/작업 비밀값을 주입한 뒤 4개 모두 통과했다. 게스트 검증용으로 운영 Slack 자격 증명을 사용하지 않았다.

검증 로그는 [checks.txt](checks.txt), TTS 수치는 위 JSON, 복원 결과는 [backup-results.json](backup-results.json)에 있다. 원본 WAV·인증 파일·암호화 백업은 git ignore인 `.vercel/review-qa/`에 있다.

## 백업 복원 관측과 남은 운영 범위

708,144바이트 암호화 백업에서 원본 2개를 격리 검증 테이블로 복원하고 SHA-256을 확인했다. 최신 삭제 상태 35개를 재적용했으며, 백업 이후 삭제한 테스트 파일이 없고 철회된 동의도 되살아나지 않음을 확인했다. 복원 DB의 실행 가능 jobs는 0개다. 자세한 관측값은 `backup-results.json`이다.

이 시험은 실제 Storage 서비스 재연결·파일 재생과 운영 서비스 재개까지 수행한 재해 복구 시험이 아니다. 운영 자동 백업, 원격 관리형 DB 연결, 별도 보관소·키 복구, 조직 관리자/설치 상태·DB grants·인덱스 재검증, Slack 첨부 실물 복원과 RPO/RTO 측정은 남아 있다. 도구의 최대 파일 합계는 512MB이며 유지보수 창에서 일관된 DB/Storage 범위를 확보해야 한다. [운영 절차와 제약](../../setup-reviewed-materials.md)을 따른다.

운영 DB 마이그레이션·Vercel 배포·실제 Slack 보존 설정은 이번 개발에서 변경하지 않았다. 부서 에이전트의 구체적인 업무·지시 방식·외부 실행 권한은 [공동 설계](../../planning/부서_에이전트_공동설계.md) 대상으로 유지한다. OCR·자동 화자 분리·정밀 문장 시간·과거 버전 자동 복구·주간 AI 요약은 이 구현의 완료 범위에 포함하지 않는다.
