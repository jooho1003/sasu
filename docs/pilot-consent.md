# 사수 파일럿 수집·이용 동의문 (consent_version 1)

> 지위: PRD §8-3 "파일럿 동의문은 D9 전에 확정"의 산출물. S0 `/consent` 화면과 슬랙 [동의합니다] DM이 **이 문서의 본문을 그대로** 보여준다(코드 상수는 이 문서를 옮긴 것이며, 문구를 바꾸면 `consent_version`을 올리고 재동의를 받는다 — PRD §6-12 동의 전이).
> 법률 자문 전 초안이다. 대회 후 자문 결과로 개정한다. `[확인 대기]` 표시는 O4(외부 공급자 데이터 설정 확인) 결과로 채운 뒤 제출 전 제거한다.

---

## 화면·DM에 표시하는 본문

**사수가 부서 기록을 모으기 전에 동의를 받습니다.**

사수는 우리 부서의 슬랙 대화, 회의 전사, 노션 원칙 문서를 읽고 "지금 결정해야 할 것"을 담당자에게 알려 주며, 내려진 결정을 원장에 남깁니다. 동의하지 않으면 **내 발언은 저장되지 않고**, 결정 카드 DM도 받지 않습니다. 동의하지 않아도 부서 업무나 평가에 어떤 불이익도 없습니다.

1. **모으는 것**
   - 연결된 슬랙 채널에서 내가 쓴 메시지(연결 시점 기준 최근 7일 포함)와 사수를 멘션해 한 질문
   - 부서장이 올린 회의 전사 파일 속 내 발언(화자 이름으로 구분)
   - 내가 사수 웹·슬랙에서 한 질문과 받은 답변 기록
   - 계정 정보: 이메일, 표시 이름, 슬랙 사용자 ID
   - 전화번호·이메일·계좌번호 등은 저장 전에 자동으로 가립니다. 음성 입력의 원본 음성은 저장하지 않습니다.
2. **쓰는 목적**: 결정이 필요한 안건 분류, 결정 카드 작성, 결정 원장 기록, 권한 범위 안에서의 질문 답변. **사람을 평가·감시하는 데 쓰지 않으며**, 사수가 AI 모델 학습용으로 제공하지 않습니다(외부 처리 사업자의 예외는 6번).
3. **보관 기간**: 파일럿 종료(2026-10-16)까지. 종료 시 또는 요청 시 조직 단위로 전량 삭제합니다. 질문 기록(감사 로그)은 파일럿 중에만 보관합니다.
4. **원장에 남는 것**: 결정의 근거로 인용된 발언 문장은 **결정 원장의 일부로 남습니다.** 채널 연결을 끊거나 동의를 철회해도 이미 원장에 인용된 문장은 지워지지 않습니다. 인용되지 않은 본문과 검색용 벡터는 채널 제거 시 삭제됩니다.
5. **누가 보나**: 같은 부서 구성원만 봅니다. 부서장 전용으로 지정된 소스(예: 경영회의 전사)는 부서장만 봅니다. 슬랙 채널에서 사수에게 물으면 채널 전원이 볼 수 있는 범위의 기록만 답에 씁니다. 조직 관리자는 멤버 목록(이름·이메일·부서·역할)과 동의 상태, 부서별 질문 수와 인용 통계를 볼 수 있습니다. 조직 관리자 권한만으로는 질문·답변·카드·원장의 내용과 질문자별 기록을 볼 수 없습니다. 조직 관리자는 새 부서의 첫 부서장을 지정할 수 있고, 지정된 부서장은 부서 설정에서 확인할 수 있습니다.
6. **외부 처리**: 분류·요약·답변 생성과 검색 벡터 계산을 위해 가려진 본문이 아래 해외 사업자에게 전송됩니다.
   - Groq, Inc.(미국) — 텍스트 분류·생성, 음성 전사. 모델 학습 사용 없음. 공급자 보존: 2026-09-14부터 조직 Data Controls의 Global ZDR·Inference APIs ZDR을 켜 입력·출력을 보존하지 않는다. 그 전 전송분은 Groq 정책상 안정성·오남용 감시 목적으로 최대 30일 보존됐을 수 있다
   - Voyage AI(미국) — 검색용 벡터 계산. 2026-09-13부터 학습 사용 거부(opt-out)가 설정되어 처리 후 즉시 삭제됩니다. 단, 설정 전인 2026-09-10~09-13에 전송된 가려진 본문은 Voyage AI 약관상 모델 개선에 쓰일 수 있습니다.
   - Supabase(데이터베이스, 리전 `[확인 대기]`), Vercel(웹 호스팅, 미국), Slack(메시지 수신·DM 발송)
7. **철회**: 세팅 화면이나 슬랙에서 언제든 철회할 수 있습니다. 철회한 뒤의 발언은 저장하지 않고 DM도 보내지 않습니다. 철회 전에 저장된 기록은 4번 규칙을 따릅니다. 파일럿 전체에서 빠지고 싶으면 부서장에게 말하면 해당 채널을 수집에서 제외합니다.

## 운영 규칙 (화면에는 표시하지 않음)

- 2026-09-15 관리자 열람 범위 추가는 ADR-044 5항에 따라 고지로 처리한다. 수집·이용 범위와 동의 버전 1은 유지한다.

- 동의는 본인만 할 수 있다. 부서장이 대신 누를 수 없다(서버에서 `auth.uid()` 또는 서명 검증된 슬랙 사용자 = 본인).
- 슬랙 DM의 [동의합니다]와 웹 S0의 [동의]는 같은 `members.consented_at`·`consent_version`을 기록한다.
- 채널 연결은 그 채널 멤버 전원이 동의한 뒤에만 가능하다(PRD §6-6).
- 본문 개정 시 `consent_version`을 올리고 해당 멤버에게 재동의를 요청한다. 파일럿 중 개정하면 수집 판정(`consented_at`)도 버전 비교로 바꾸는 후속 작업이 필요하다 — MVP는 버전 1 고정.
- 파일럿 구성원 전원의 서면 동의(이 문서 본문 기준)를 D9(9/16) 전에 받는다.
