# 사수 v2.1 — MVP 3주 개발 일정표

> 기간: **2026-09-01(화) ~ 09-20(일)** · 목표: 결정 카드 + 권한별 답변이 **실제로 도는** 수직 슬라이스
> 원칙: 회의록은 커머디티(검증된 엔진 사용), 우리 시간은 **결정 레이어**에 쓴다.

## 데모 필수 장면 3 (이것만 지키면 이긴다)

1. 폰 원탭 녹음 → 자동 업로드 → 3분 뒤 화자별 회의록
2. 담당자 슬랙에 **지금 결정 카드** 도착 (과거 결정 충돌 인용 포함)
3. 같은 질문에 **팀장/신입 계정의 답이 다른** 권한 인지 Q&A

## 컷 리스트 (일정이 밀리면 이 순서로 버린다)

| 순위 | 기능 | 대체 |
|---|---|---|
| 1 | 캘린더 연동 알림 | 수동 원탭만 (제품 서사는 로드맵으로 설명) |
| 2 | 실시간 화자 인식 시연 | 사전 처리된 샘플 회의로 시연 |
| 3 | 공유 카드 자동 생성 | 디자인 툴로 만든 정적 카드 3종 |
| 4 | 검토 노트(충돌 감지) 자동 | 샘플 데이터에 수동 큐레이션된 충돌 1건 |
| 5 | 슬랙 연동 | 웹 인박스로 결정 카드 수신 |

**절대 못 버리는 것**: 결정 카드, 결정 원장, 권한별 답변 차이. 이 셋이 빠지면 Otter와 다를 게 없어진다.

## 기술 스택 (기획서 §08 고정)

- Next.js(App Router) + Vercel / Supabase(Postgres + RLS + pgvector + Storage)
- 전사: Whisper 계열 STT + 상용 diarization(음성 등록 30초 → 매칭, 교정 UI 필수)
- 정리·답변: Claude Opus 5 (인용 스키마 강제) / 검증·추출: Claude Haiku 4.5 + 규칙 휴리스틱, 비동기는 Batch API
- 마스킹: 정규식 선마스킹 + Presidio / 감사 로그 테이블 첫날부터

## 상시 원칙

- **매일 우리 회의를 사수로 처리한다** — 개발 기간 자체가 파일럿 1호이자 데모데이 실데이터의 출처.
- 모든 회의 녹음은 참석자 고지·동의 후 진행 (법적 전제, 기획서 §03).
- Claude Code 세션 로그를 매일 아카이브 — 제출서 "사용한 AI 툴" 부록 재료.
