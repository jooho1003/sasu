# 부서별 회고 커넥터 — 브라우저 직접 확인 기록 (2026-09-19)

- 방법: 앞선 4개 조사 파일에서 "SPA라 확인 못 함"으로 남은 항목을 Chrome으로 직접 열어 공식 문서 원문을 읽었다. 요약이 아니라 원문 표·필드를 옮겼다. 확인 못 한 항목은 그대로 남긴다.
- 결론 3줄: ① Google `drive.activity.readonly`는 **Restricted scope**다 — Drive Activity 커넥터는 서버 저장 시 CASA 평가 대상이라 설계에서 뺀다. ② Zendesk(`/users/{id}/tickets/assigned`, Agents)·Linear(`IssueHistory`)·세일즈맵(딜 액티비티·노트, 시간·작성자 필터, 개인 토큰)·채널톡(응답 필드)·Confluence(버전 상세에 `page.body`)·Jira changelog 스코프·Figma Version 필드·Mailchimp `since_send_time`·스티비 `GET /v2/emails`·원티드 ATS가 확정됐다. ③ 네이버 검색광고 문서는 브라우저 도메인 권한이 없어 여전히 미확인이고, Zoom Phone은 계정 관리자 앱이라 원칙(개인 연결)과 충돌해 더 조사하지 않았다.
