# 마케팅·콘텐츠: 승인된 표현과 실험의 조건

입력은 브랜드 가이드·캠페인 의사결정·제품팀이 공개한 사실과 변경 이력이다. 광고 계정·실시간 전환율·집행 예산 데이터 연동은 가정하지 않는다. 규제성 표현은 최신 전문 검토가 필요한 별도 업무이며 사수의 문서 점수로 적합 판정을 내리지 않는다.

| 페르소나·상황 | 실제 이용 방식 | 장점 가설 | 단점·실패 조건 | S/M 차이·검증 질문 |
|---|---|---|---|---|
| **MK-L1 콘텐츠 주니어**. 표현·톤 확인 | ASK로 승인 문구의 맥락 확인 → 원문 대상/시점 확인 → 초안은 기존 편집도구 작성 | 선임의 반복 문구 설명을 줄임 | 오래된 캠페인의 예외 표현 재사용, 텍스트만 보고 실제 이미지 판단(G06·G09) | S는 대표가 브랜드 판단. M은 상품/매체별 가이드. **승인된 문구의 조건을 함께 옮기는가?** |
| **MK-L2 캠페인 담당자**. 카피·타깃·기간 변경 | 논의를 카드로 정리 → 사람 결정 → 집행은 광고도구에서 별도 수행 → 결과 요약 연결 | 무엇을 언제 왜 바꿨는지 남아 회고에 도움 | 자동 집행/실험 결과 수집 없음. 결정 완료를 집행 완료로 오해(G15·G16) | S는 제작/집행/분석 겸임. M은 콘텐츠/퍼포먼스/제품 협의. **아직 집행하지 않은 결정을 구별하는가?** |
| **MK-L3 브랜드·그로스 선임**. 문구·실험 설계 검토 | 역할 평가로 확정된 자료의 체크리스트 누락 확인, 점수 대신 근거 검토 | 검토 기준을 공개하고 일관성 높일 가능성 | 가중치를 잘못 정하면 얕은 문구가 높은 점수. 성과 인과관계는 문서만으로 모름(G10·G17) | S는 실험 승인도 담당. M은 브랜드 품질과 성장 목표가 다름. **기준을 바꾸면 왜 결과가 바뀌었는지 보이는가?** |
| **MK-L4 마케팅 팀장**. 예산·일정·표현 예외 | 미결 카드의 사실/추천 구분 → 명시적 결과 기록 → 후속 집행 담당 확인 | 회의 후 정리 누락·승인 반복 감소 가능 | 입력이 불완전하거나 타 부서가 공개 안 한 사실을 마케팅이 확정해 버림(G01·G07·G08) | S는 예산대표 승인 별도. M은 재무/법무/제품 수락 필요. **제품 사실의 최종 확인 주체가 표시되는가?** |
| **MK-L5 CMO·사업 책임자**. 채널 투자·브랜드 위험 | 공유된 결정 요약과 실제 성과 보고를 함께 검토 | 과거 선택 이유를 숫자 보고 옆에서 이해 | 사수만으로 ROI·시장 변화·최신 성과를 알 수 없음(G06·G16·G20) | S는 즉각적 비용 체감. M은 정보 최신성·부서별 성과정의 차이. **데이터 없는 설명에 숫자를 만들어 붙이지 않는가?** |

한 캠페인에 대해 ‘승인된 표현/적용 기간/결정 이유/실제 집행 여부’를 구별하는 테스트를 우선한다. 콘텐츠 생성량을 편익 지표로 잡지 않는다.
