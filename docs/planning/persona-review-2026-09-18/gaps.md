# 부족한 부분 별도 기록

상태는 모두 **검토·설계 제안**이다. 이 표에 들어갔다고 실제 장애·보안 취약점이 확정되거나 구현이 승인된 것은 아니다. R/C/D/H는 [증거 등급](evidence.md), S/M은 [규모 가정](scope-and-size.md)이다.

우선순위는 검토자의 판단이다. **P0** 사람 의사와 기록의 직접 불일치, **P1** 핵심 흐름/책임 경계를 막아 파일럿 전에 다룰 것, **P2** 반복 사용·확장 검증 뒤 할 것. 빈도·매출 규모를 임의로 숫자 점수로 환산하지 않았다. ‘M 선행’은 중견 규모의 해당 업무에 적용하기 전에 충족할 조건이다.

외부 고객 데이터를 넣는 확대, 비공개 자료를 여러 부서에 공유하는 확대, 회사 승인 규칙을 바꾸는 확대는 문서 제안만으로 운영에 적용하지 않는다. 이 원칙은 이미 있는 PRD의 운영 검증·승인 절차를 따른다.
