## 1. 개요

원천 [PRD DC-07·DC-15·§8](../../PRD.md), [ARCHITECTURE §6-12](../../ARCHITECTURE.md), [ADR-085](../../ADR.md). 사용자의 next step 요청으로 기존 결정함의 회복 동작을 보완한다.

## 2. 범위

포함: 로딩/빈 목록/오류·수동 공유 갱신, 현재 카드 상세·읽음·연타 잠금, 성공/중복 성공 목록 복귀, 실패 초안, 탭/세션 종료 콜백 폐기.
제외: 새 API/DB/모델·권한 함수·자동 결정/결정 대기열·서버 행동 취소·SMTP/새 설치 파일.

## 3. 요구사항

PRD DC-15와 design U1~6/S1~2를 비교한다. 기존 서버가 권한/원장/멱등을 집행한다. 인용 없는 카드 내용과 행동은 표시하지 않는다. 새 영구 캐시 없음.

## 4. 성공 조건

SC1 로딩·오류·빈 목록 분리/재시도·한국어 상태. SC2 상세 현재 조회·연타 1회·인용 확인 뒤 읽음·인용 없음 복귀. SC3 결정/보류/반려/중복 성공은 목록 복귀·새로고침, 실패는 입력 유지·자동 재전송 없음. SC4 늦은 조회/처리/읽음 오류가 이탈/로그아웃 후 화면을 바꾸지 않음. SC5 Electron 회귀·단위/lint/build·SQL·독립 분석/도구/보고 기록.

## 5. 위험

이미 시작한 POST는 이탈로 취소되지 않는다. 실패/응답 소실 뒤 자동 재시도하지 않고 현재 목록/상세에서 결과를 재확인한다. 늦은 콜백은 현재 화면 세대로 검사한다.

## 6. 영향 분석

App→CardsTab→CardView만 제품 변경. App loadInbox/rememberSeen은 phase45 공유 계약 그대로. 영향 소비자 최근 작업·질문/세션 종료·펫은 회귀한다. main/preload/공유 계약/서버/SQL 무변경.

## 7. 구조·대안

A 기존 컴포넌트의 props·ref·cleanup 보완(선택), B 새 hook/저장소(이 기능에는 과다), C 새 API와 optimistic 갱신(원장/권한 영향). 기존 lifecycle 경계를 작은 변경으로 완성한다.

## 8. 규약

기존 React/TS/한국어·직접 shared/messages import·native 버튼/label. 새 lib 모듈 없음. 합성 API와 SQL 실제 권한 증거를 구분한다.
